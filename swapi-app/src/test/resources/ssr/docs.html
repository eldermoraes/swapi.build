Documentation

RESTful public API with data about the Star Wars universe. All successful GETs return 200; nonexistent ids return 404. The same data is also exposed as an MCP server (Streamable HTTP) at /mcp.

OpenAPI 3.1.0 · version {{VERSION}} · Download the spec and generate a client: npx @openapitools/openapi-generator-cli generate -i /openapi.json -g typescript-fetch

Root

API entry point

GET /api
List all available resources — Returns the URLs of every resource collection, built from the request's base URL.

Films

Star Wars films

GET /api/films?search=hope
List all films — Returns every film, or only those whose title matches the search query.
GET /api/films/{id}
Get a film by id 200 / 404
GET /api/films/random
Get a random film

Stats

Public, anonymous usage counters

GET /api/stats
Request counts per route for the last 24 hours, 7 days or 30 days — Totals per route template (for example /api/people/{id} or /mcp) and per group (rest, mcp, pages, seo, other), a trend per hour or per UTC day, and the same totals for the window right before, for comparison. Counted with no IP address, no User-Agent and no other data about the client. Without parameters: the last 7 days, per day.
