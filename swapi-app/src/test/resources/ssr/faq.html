FAQ

Answers about swapi.build, the free Star Wars API and MCP server, and how it compares with other Star Wars APIs.

What is swapi.build?

swapi.build is a free, open-source Star Wars API. It serves the same data two ways: a REST JSON API under /api and a remote MCP server at /mcp that AI agents call directly.

It is built with Quarkus and compiled with GraalVM into a native binary. Every page whose content the server draws is also plain Markdown at the same address plus .md; the copy of the home is /index.html.md.

Is it free? Do I need an API key or an account?

It is free. There is no API key, no account and no sign-up: every endpoint is public and read-only, on the REST API and on the MCP server.

What data does it have?

Six types of records from the six films of Episodes I-VI: 6 films, 82 people, 60 planets, 37 species, 36 starships and 39 vehicles.

There is nothing from the sequels, the series or the games. swapi.dev, swapi.tech and swapi.info cover the same six films and 82 people; the comparison below has the details.

Is the data the same as SWAPI's?

Yes. The records come from the original SWAPI, created by Paul Hallett and maintained by Juriy Bura, with the same ids and fields. The links inside each record point to this API instead of swapi.dev.

How is it different from swapi.dev?

Lists and searches return a plain JSON array of every matching record, like swapi.info, instead of pages of count, next and results.

It also has a remote MCP server for AI agents and a published OpenAPI contract, which swapi.dev does not list in its documentation. Both serve the same records with no API key.

Why is /api/films/1 A New Hope and not Episode I?

Ids are record ids, not episode numbers. The films were added in release order, so /api/films/1 is A New Hope (Episode IV) and /api/films/4 is The Phantom Menace (Episode I).

Each film has an episode_id field with its episode number.

How do I connect an AI agent?

Point any MCP client at the Streamable HTTP endpoint /mcp on this site. There is no authentication.

The agent gets four tools (sw_search, sw_get, sw_list and sw_random), a resource for every record and the character_profile prompt.

  • MCP server guide

Which MCP clients work?

The MCP server guide has step-by-step setup for Claude Code, Claude Desktop and claude.ai, OpenAI Codex, GitHub Copilot and IBM Bob. Any other client that speaks Streamable HTTP works with the same URL.

  • MCP server guide

Is there an OpenAPI contract?

Yes: /openapi.json is generated from the code of the version that is running, so it always matches the API. The REST documentation is drawn from it.

How do I know it is up?

A public monitor in GitHub Actions is scheduled every 15 minutes: 649 of 650 scheduled checks of GET /api/people/1 passed between 19 October and 28 October 2026. The schedule is best-effort, so some 15-minute windows have no check, and the monitor only checks that one request, the certificate and DNS.

The usage stats page shows how many requests the site answered in the last 24 hours, 7 days and 30 days.

  • Usage stats

Can I use the code?

Yes. The code is open source under the Apache License 2.0. The data comes from the original SWAPI (see the answer above), and all Star Wars content belongs to Lucasfilm Ltd. and Disney.
