Endpoint

{#codeBlock id="endpoint" lang="plain" content=view.endpoint /}
Streamable HTTP — both paradigms on one endpoint. Clients on the stateless spec (2026-07-28) send self-contained requests: no initialize handshake, no session ids, nothing to keep alive between calls. Clients on earlier revisions negotiate a session and work just as well, and keep working after a server restart: a session id the server no longer knows is simply issued a fresh session instead of failing. First-party, read-only, no authentication.

Claude Desktop & claude.ai

  1. Open Settings → Connectors and click Add custom connector.
  2. Name it swapi-build and paste the URL: {view.endpoint}.
  3. Save — no authentication is required.

Verify: in any chat, the + menu → Connectors lists swapi-build with its tools.

Available on all plans (Free allows one custom connector). On Team/Enterprise an Owner adds it under Organization settings → Connectors.

Troubleshooting

Probing /mcp with raw curl? Stateless requests must include the MCP-Protocol-Version, Mcp-Method and Mcp-Name headers — MCP clients send these automatically.
